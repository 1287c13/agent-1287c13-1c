# Слой данных: 1c-mcp-toolkit

## Что это
`MCP_Toolkit.epf` — внешняя обработка 1С, которая поднимает HTTP-сервер **внутри
самой 1С**. Cline подключается к ней по MCP (`streamableHttp`). Публикация базы
на IIS/Apache и COM-соединение не нужны, конфигурация не меняется.

## Запуск

1. Откройте `MCP_Toolkit.epf` в 1С:Предприятие (Файл → Открыть, либо
   `scripts\run-1c.ps1 -Execute "C:\w\1c\агент\mcp\1c-mcp-toolkit\MCP_Toolkit.epf"`).
2. В форме выберите режим **«Встроенный сервер»**.
3. Нажмите **«Запустить сервер»** (порт по умолчанию 6003).
4. Проверьте из терминала:
   ```powershell
   .\scripts\run-query.ps1 -Query 'ВЫБРАТЬ ПЕРВЫЕ 1 Ссылка ИЗ Справочник.Номенклатура'
   ```

## Подключение к Cline
Блок уже есть в `mcp\cline_mcp_settings.example.json` (`1c-toolkit`):
`http://localhost:6003/mcp`, `"type": "streamableHttp"`.

## Важно
* Обработка должна быть **открыта**, пока слой данных нужен агенту.
* Права: агент работает от имени пользователя, под которым открыта обработка.
* Для «только чтения» ограничьте состав данных и не включайте инструменты записи
  (см. `docs\07-capabilities-and-limits.md`).
* Прокси-режим (Python + Docker) не требуется — он нужен только если база не
  открывается локально.
