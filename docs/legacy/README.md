# Документация первой версии харнесса

Здесь лежат файлы, написанные до того, как харнесс собрали в этом репозитории. Они
описывают первую раскладку: бинарники MCP в `mcp\` (а не в `.cline\mcp\`), скиллы
глобально в `~\.cline\skills`, скрипты `install-skills.ps1`, `setup-code-index.ps1`,
`start-code-index.ps1`, которых в репозитории больше нет.

Смысл каталога - история: по этим файлам видно, откуда взялись текущие решения.
Руководствоваться ими нельзя: актуальное описание - `docs\01-architecture.md` ..
`docs\06-troubleshooting.md`, инструкция по установке - `README.md` в корне.

| Файл | Что описывал |
|------|--------------|
| `README-v1.md` | инструкция по установке первой версии |
| `SOURCES-v1.md` | источники и версии первой сборки |
| `00-checklist.md` | чек-лист "с нуля до первой задачи" |
| `01-architecture.md` | архитектура первой версии |
| `02-mcp-setup.md` | настройка MCP через глобальный конфиг Cline |
| `04-troubleshooting.md` | диагностика первой версии |
| `05-cline-from-scratch.md` | установка VS Code + Cline |
| `06-first-task.md` | как дать агенту первую задачу |
| `07-capabilities-and-limits.md` | возможности и ограничения |
