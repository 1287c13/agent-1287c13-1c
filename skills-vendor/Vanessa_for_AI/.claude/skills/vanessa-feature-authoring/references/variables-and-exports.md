# Переменные и экспортные сценарии

## Явные параметры

Локальные переменные вызывающего сценария не становятся входами экспортного сценария автоматически. Объявляй входы в имени экспортного сценария и передавай значения явно.

Проверяй точное имя вызываемого сценария поиском по проекту. Не принимай похожее имя за существующий шаг.

## Область и интерполяция

Выбирай `$Имя$` и `$$Имя$$` по числу оставшихся границ раскрытия экспортных сценариев:

- прямой исполняемый UI-шаг обычно использует `$Имя$`;
- значение, которое должно пережить ещё одно раскрытие экспортного сценария, может требовать `$$Имя$$`;
- запись в `КонтекстСохраняемый` сама по себе не доказывает необходимость двойного доллара.

Подтверждай форму runtime-проверенным вызовом того же класса. Ошибка с буквальным `$Значение$` в ожидаемом тексте указывает на лишний уровень экранирования.

## Сериализация

Не помещай объекты TestClient UI в `Контекст` или `КонтекстСохраняемый`, если значение может передаваться клиент-сервер. Сохраняй сериализуемые строки: имена, ссылки и простые значения.

Удаление переменной Vanessa не удаляет и не помечает на удаление соответствующий объект 1С.
