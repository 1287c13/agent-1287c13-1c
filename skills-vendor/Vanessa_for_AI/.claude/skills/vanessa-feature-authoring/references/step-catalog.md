# Локальный каталог шагов

## Поиск

Каталог по умолчанию: `knowledge/vanessa-automation/steps-library.json`.

Ищи точечным запросом:

```powershell
rg -n -i 'ключевые слова шага' knowledge/vanessa-automation/steps-library.json
```

После совпадения прочитай только небольшой контекст записи и проверь:

- `example` — пример текста шага;
- `signature` — параметры реализации;
- `description` и `group` — назначение;
- `kind` — обычный шаг или условие;
- `source_file` и `source_line` — происхождение;
- метаданные версии каталога.

## Ограничения

- Наличие записи доказывает регистрацию шага в указанном исходном релизе.
- Оно не доказывает, что библиотека подключена в окружении пользователя.
- Оно не доказывает имена UI-элементов конфигурации.
- Встроенный каталог не заменяет каталог версии пользователя.
- Динамическое или неразобранное выражение генератора нельзя использовать как готовый шаг.

При конфликте версий покажи пользователю найденную запись и запроси подтверждение шага в его «дереве известных шагов» или запись сценария.
