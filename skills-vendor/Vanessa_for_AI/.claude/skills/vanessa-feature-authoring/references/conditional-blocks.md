# Условные блоки

Отступ после `Если <шаг> Тогда` управляет выполнением, а не только оформлением файла.

1. Оставляй `Если ... Тогда` на уровне окружающих шагов сценария.
2. Сдвигай каждое условное действие ровно на один дополнительный уровень — обычно на четыре пробела.
3. Возвращай первый безусловный шаг после блока на уровень `Если`.
4. Не оставляй условие и предназначенное для него действие на одном уровне: Vanessa выполнит действие безусловно.
5. Перед передачей проверь границы каждого изменённого блока `Если ... Тогда`.

Правильно:

```gherkin
И я перехожу к закладке с именем "ПодтвержденноеИмяЗакладки"
Если появилось окно с заголовком "ПодтвержденныйЗаголовок" Тогда
    И я нажимаю на кнопку с именем "ПодтвержденноеИмяКнопки"
И я нажимаю на гиперссылку с именем "ПодтвержденноеИмяГиперссылки"
```

Неправильно:

```gherkin
Если появилось окно с заголовком "ПодтвержденныйЗаголовок" Тогда
И я нажимаю на кнопку с именем "ПодтвержденноеИмяКнопки"
```

Правило подтверждено runtime-прогоном рабочего сценария; точная версия Vanessa Automation в источнике не зафиксирована.
