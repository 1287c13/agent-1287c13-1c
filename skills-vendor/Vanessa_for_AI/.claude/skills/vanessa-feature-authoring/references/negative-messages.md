# Ожидаемые ошибки и сообщения пользователю

Текст ожидаемой бизнес-ошибки в 1С проверяй как сообщение пользователя, а не как автоматически падающее исключение Vanessa Automation.

## Изолируй целевое действие

Очисти накопленные сообщения непосредственно перед единственным действием, которое должно вызвать ошибку:

```gherkin
И я очищаю окно сообщений пользователю
Когда я нажимаю на кнопку с именем "ПодтвержденноеИмяКнопки"
Тогда в логе сообщений TestClient есть строка "Подтвержденный текст ошибки"
```

Текст, имя кнопки и состояние после действия должны быть подтверждены записью или runtime-диагностикой текущего окружения.

## Учитывай семантику версии

Для встроенного каталога Vanessa Automation `1.2.043.28` исходным кодом подтверждено:

- `в логе сообщений TestClient есть строка` выполняет регистронезависимый поиск подстроки, а не точное равенство;
- `в логе сообщений TestClient есть сообщения только из списка` сопоставляет элементы как регистронезависимые подстроки и перед сравнением набора удаляет дубликаты фактических текстов;
- если дубликаты должны приводить к ошибке, добавь `И в сообщениях пользователю нет одинаковых сообщений`.

Для другой версии сначала проверь реализацию шага или runtime-поведение. Вариант по шаблону используй только для подтверждённых динамических фрагментов.

## Проверь постусловие отдельно

После сообщения независимо проверь подтверждённое состояние формы или другой результат неуспешного перехода. Сам текст ошибки не доказывает, что объект не был сохранён, проведён или переведён в бизнес-статус.

Если действие могло оставить черновик или другой постоянный объект, установи это runtime-прогоном и добавь очистку данных. Закрытие окон TestClient и удаление переменных Vanessa не очищают базу.

`ВыбратьСообщениеПользователю()` считай UI-действием, способным изменить фокус. Используй его для проверки перехода от сообщения к проблемному полю, но не вместо читаемого утверждения текста.

Для проверки независимости запускай негативный сценарий отдельно. Если у него есть парный позитивный сценарий, проверь оба порядка запуска в одной сессии Vanessa Automation, когда состояние сообщений или тестовых данных может протекать между сценариями.
