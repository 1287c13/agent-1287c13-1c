# Тестовые данные и очистка

## Данные

- Создавай объект под тестом с уникальным значением.
- Соблюдай проектный префикс; для нового проекта предложи `ВА_`, но не навязывай без согласования.
- Выбирай зависимости по явному бизнес-ключу, а не по первой строке списка.
- Сохраняй навигационные ссылки созданных объектов, когда этот способ подтверждён.
- Не храни реальные пароли и токены; получай их из переменных окружения.

## Независимость

Сценарий должен создавать или находить необходимое окружение и не зависеть только от порядка обхода файлов. Повторный запуск не должен случайно использовать данные предыдущего неуспешного запуска.

## Очистка

1. Построй граф зависимостей до реализации.
2. Очищай созданные самостоятельные данные в обратном порядке зависимостей.
3. Не удаляй общую подготовленную зависимость, если проект требует её для последующих сценариев.
4. Используй проектные экспортные сценарии очистки вместо дублирования UI-последовательностей.
5. Учитывай, что обычные последние шаги не выполнятся после падения; если проект использует гарантированный хук завершения, проверь его контракт.

Не скрывай провал очистки удалением только Vanessa-переменных.
