# Инициализация проекта Vanessa Automation

Сначала исследуй, затем спрашивай. Не создавай каталоги и файлы до согласования структуры пользователем.

## Исследуй проект

1. Прочитай корневые инструкции и README.
2. Найди существующие `.feature`, ближайшие README, настройки Vanessa Automation и пути библиотек.
3. Проверь соглашения об именовании, группировке, экспортных сценариях, тестовых данных и очистке.
4. Считай проект пустым только когда эти сведения нельзя вывести из файлов.

Полный список проверок находится в [references/bootstrap-checklist.md](references/bootstrap-checklist.md).

## Уточни недостающие решения

Для пустого проекта уточни только то, что нельзя узнать из репозитория:

- корневой каталог, который загружает Vanessa Automation;
- группировку по бизнес-областям, объектам или типам проверок;
- место для переиспользуемых `@ExportScenarios`;
- правила именования каталогов, файлов и тестовых данных;
- требования к независимости запуска и очистке;
- название и версию конфигурации 1С, язык интерфейса и версию Vanessa Automation.

Если пользователь делегирует выбор, предложи минимальный вариант для первого сценария, а не полное дерево наперёд.

## Предложи структуру

Покажи:

1. небольшое дерево создаваемых каталогов;
2. назначение каждого каталога;
3. расположение исполняемого сценария и библиотечных зависимостей;
4. какие README будут фиксировать проектные и runtime-подтверждённые факты;
5. какие решения пока отложены.

Не включай пустые бизнес-разделы «на будущее». Не копируй структуру другого проекта без объяснения её соответствия текущей задаче.

## Дождись подтверждения

До ответа пользователя не создавай структуру и не переходи к авторингу сценария. После подтверждения создай только согласованный минимум и передай работу skill `vanessa-feature-authoring`.

## Результат

Сообщи:

- согласованное дерево;
- созданные или изменённые файлы;
- принятые соглашения;
- решения, которые потребуются при появлении новых областей;
- что runtime-проверка структуры Vanessa Automation ещё не выполнялась, если пользователь её не подтвердил.
