# Каталог шагов Vanessa Automation

`steps-library.json` — детерминированный индекс статически зарегистрированных шагов из `features/Libraries` Vanessa Automation. Встроенная версия собрана из тега `1.2.043.28`, commit `f3a01778a14d29b38204685deea0131274d438ff`.

Для каждой разрешённой регистрации сохраняются пример, сигнатура, процедура, описание, группа, тип, относительный исходный файл и строка. Регистрации с вычисляемыми во время исполнения выражениями не угадываются: они перечислены в `unresolved`.

`content_sha256` — SHA-256 канонического UTF-8 JSON-массива `steps` с сортировкой ключей и без пробелов. В метаданных намеренно нет времени сборки, поэтому один исходный commit создаёт побайтно идентичный файл.

Это справочник синтаксиса, а не доказательство работы шага в конкретной конфигурации 1С. Приоритет источников описан в корневом README.
