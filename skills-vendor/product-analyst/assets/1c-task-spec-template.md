**წესები:**
- ტიპი — მხოლოდ კონკრეტული: `СправочникСсылка.Контрагенты`, `Число(15,2)`, `Строка(150)`. „სტრიქონი" სიგრძის გარეშე ტიპი არ არის.
- `Строка` — ფიქსირებული თუ ცვლადი; **შეუზღუდავი სიგრძე** აღნიშნე ცალკე (გავლენა ინდექსირებასა და მონაცემთა შერჩევაზე — запрос).
- `Дата` — მიუთითე **თარიღის შემადგენლობა**: თარიღი / დრო / თარიღი და დრო.
- **შედგენილი ტიპი** — ჩამოთვალე შემადგენლობა და გაითვალისწინე: აუარესებს მონაცემთა შერჩევის (запрос) წარმადობას.
- სავალდებულოობა — „Проверка заполнения = Выдавать ошибку" + **როდის**: ჩაწერისას თუ გატარებისას.
- კავშირები — მიუთითე რომელი: `Параметры выбора` / `Связи параметров выбора` / `Связь по типу`.
- ინდექსი — ითხოვე მხოლოდ დასაბუთებით (რა შერჩევა/ძებნა იქნება ამ ველით).
