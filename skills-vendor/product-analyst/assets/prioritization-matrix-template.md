# პრიორიტიზაციის მატრიცები — შაბლონი

> აირჩიე ერთი ჩარჩო გაცნობიერებულად და **თქვი, რას ვერ ხედავს ის**. რანჟირება, რომელსაც თან არ ახლავს ბრმა ზონის აღწერა, მომდევნო კვირას ხელახლა გასაჩივრდება.
> შეფასებული (და არა გაზომილი) რიცხვი აღნიშნე `[შეფასება]`-თი. გაზომილ 2000-სა და გამოცნობილ 2000-ს შორის განსხვავება მთელი სავარჯიშოს სანდოობაა.

## RICE

`RICE = (Reach × Impact × Confidence) ÷ Effort`

| # | ელემენტი | Reach *(რამდენს შეეხება, პერიოდში, ერთეულით)* | Impact *(3/2/1/0.5/0.25)* | Confidence *(100/80/50%)* | Effort *(კაც-თვე)* | **RICE** | წყარო |
|---|---|---|---|---|---|---|---|
| 1 | | | | | | | ანალიტიკა / `[შეფასება]` |

**რას ვერ ხედავს:** სამი გამოცნობილი რიცხვის ნამრავლი გამოიყურება როგორც ზუსტი მაჩვენებელი · დიდი Effort მნიშვნელში + დაბალი Confidence ახალზე სისტემატურად კლავს დიდ ფსონებს და ზემოთ წევს მცირე გაუმჯობესებებს · ახალი პროდუქტისთვის Reach უცნობია და ჩარჩო „არ ვიცით"-ს ჩუმად რიცხვად აქცევს · დამოკიდებულებები და სტრატეგიული თანმიმდევრობა უხილავია.

## ICE

`ICE = Impact × Confidence × Ease`, თითოეული 1–10 *(Ease — რაც უფრო მაღალია, მით უფრო ადვილია)*

| # | ელემენტი | Impact | Confidence | Ease | **ICE** |
|---|---|---|---|---|---|

**რას ვერ ხედავს:** „7"-ის საერთო განმარტება არ არსებობს, ამიტომ ორი ადამიანი სხვადასხვა რანჟირებას იძლევა და ერთი და იგივე ადამიანიც სხვადასხვა დღეს · ერთეულებზე მიბმა საერთოდ არ არის, ამიტომ ქულები არ შეედრება არც გუნდებს შორის, არც დროში · Ease-ის დაბალი ქულა მკვეთრად ჩამოწევს შედეგს, რაც გუნდს მხოლოდ ადვილი საქმეებისკენ წევს.

## WSJF

`WSJF = (Value + Time Criticality + RR/OE) ÷ Job Size`

**ქულები მოდიფიცირებული ფიბონაჩით: 1, 2, 3, 5, 8, 13, 20. აწერე სვეტ-სვეტ: იპოვე სვეტში ყველაზე მცირე, მიეცი 1, დანარჩენი შეაფასე მის ჯერადად. სტრიქონად არასოდეს.**

| # | ელემენტი | Value | Time Criticality | RR/OE | **CoD** | Job Size | **WSJF** |
|---|---|---|---|---|---|---|---|
| 1 | | | | | | | |

- **Value** — პირდაპირი ეკონომიკური სარგებელი
- **Time Criticality** — რამდენად სწრაფად კარგავს ღირებულებას. ეს **სისწრაფეა, და არა მნიშვნელოვნება** — ძალიან ღირებული, მაგრამ უვადო საქმე სამართლიანად იღებს დაბალ ქულას
- **RR/OE** — რისკის შემცირება ან მომავალი შესაძლებლობის გახსნა
- **Job Size** — შედარებითი ძალისხმევა

**რას ვერ ხედავს:** თუ სვეტები 1-ზე არ არის დამაგრებული, ყველაფერი 8 ან 13 ხდება და მეთოდი კარგავს გამრჩევ ძალას · Job Size მნიშვნელშია და ყველაზე ადვილად სამანიპულაციო რიცხვია · სამი რიგითი ქულის შეკრება მათემატიკურად შინაარსიანი არ არის — მიიღე როგორც რანჟირების ხერხი · დამოკიდებულებები და სწავლის ღირებულება უხილავია, ამიტომ კვლევითი სპაიკი ყოველთვის წააგებს.

## Opportunity scoring

`Opportunity = Importance + max(Importance − Satisfaction, 0)`

*გამოკითხე **სასურველი შედეგები**, და არა ფუნქციები, 1–10 შკალით.*

| # | სასურველი შედეგი | Importance | Satisfaction | **Opportunity** | ინტერპრეტაცია |
|---|---|---|---|---|---|
| 1 | | | | | >15 არასაკმარისად მომსახურებული · 10–15 ადეკვატური · <10 **გადამეტებული** |

*ყველაზე დაუფასებელი შედეგი — ბოლო ზოლი: სად ვხარჯავთ ზედმეტს. ERP-ში სწორედ ასე იპოვება დამუშავებები, რომლებსაც არავინ იყენებს.*

## Kano

ორი კითხვა თითო ფუნქციაზე, ერთი და იმავე 5-ბალიან შკალაზე:
**ფუნქციური:** „როგორ იგრძნობდით თავს, პროდუქტს რომ ჰქონდეს `<ფუნქცია>`?"
**დისფუნქციური:** „როგორ იგრძნობდით თავს, პროდუქტს რომ **არ** ჰქონდეს `<ფუნქცია>`?"

პასუხის ვარიანტები: *ძალიან მომეწონებოდა · ასე ველოდები · სულერთია · შემიძლია მოვითმინო · ძალიან არ მომეწონებოდა.*

| # | ფუნქცია | A | O | M | I | R | Q | **Better = (A+O)/სულ** | **Worse = −(O+M)/სულ** | კატეგორია |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | | M / O / A / I / R |

*M = საბაზისო · O = ხაზოვანი (წარმადობის) · A = მიმზიდველი · I = ინდიფერენტული · R = შებრუნებული · Q = კითხვის დეფექტი.*

**პრიორიტეტების თანმიმდევრობა:** ჯერ დაიცავი ყველა M → ინვესტირება O-ში იქ, სადაც კონკურენციას აპირებ → შერჩევით დაამატე A → I და R არ აშენო.

**მინიმუმ 30 პასუხი თითო სეგმენტზე.** Q-ს მაღალი წილი შენი ფორმულირების დეფექტია და არა რესპონდენტის დაბნეულობა.

**რას ვერ ხედავს:** მიმზიდველი თვისებები დროთა განმავლობაში საბაზისოდ იქცევა — კვლევას ვარგისიანობის ვადა აქვს · ეკითხება ადამიანებს ისეთ ფუნქციებზე, რომლებიც არასოდეს გამოუყენებიათ, ანუ ზომავს განცხადებულ პრეფერენციას და არა ქცევას ან გადახდის მზაობას · არაფერს ამბობს ღირებულებაზე, განხორციელებადობაზე და სტრატეგიაზე.

## Impact / Effort

| | დაბალი ძალისხმევა | მაღალი ძალისხმევა |
|---|---|---|
| **მაღალი ეფექტი** | **სწრაფი მოგება** — გააკეთე ახლა | **დიდი ფსონი** — გააკეთე გააზრებულად, დაგეგმვის შემდეგ |
| **დაბალი ეფექტი** | **შემავსებელი** — თავისუფალი დროისთვის | **უფსკრული** — არ გააკეთო |

| # | ელემენტი | ეფექტი (1–5) | ძალისხმევა (1–5) | კვადრანტი | პასუხისმგებელი |
|---|---|---|---|---|---|

*ჯერ შეათანხმე, **რას ნიშნავს „ეფექტი"** (შემოსავალი? შენარჩუნება? დროის დაზოგვა?) და **რას ნიშნავს „ძალისხმევა"** (დრო? სირთულე? დეფიციტური სპეციალისტი?) — და მხოლოდ ამის შემდეგ განალაგე. კამათი განლაგებაზე თავად არის შედეგი.*

**რას ვერ ხედავს:** ვარაუდობს, რომ ელემენტები დამოუკიდებელია, ამიტომ დამოკიდებულებები ქრება · სტრუქტურულად სწრაფ მოგებას დიდ ფსონზე უკეთესად აჩვენებს, ამიტომ მხოლოდ ამ მატრიცით მომუშავე გუნდი არასოდეს აკეთებს სტრატეგიულად მნიშვნელოვანს.
