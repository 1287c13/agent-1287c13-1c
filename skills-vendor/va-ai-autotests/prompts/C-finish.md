# Вариант C+, этап «Доводка»

Человек записывает процесс рекордером VA по памятке из skill (раздел «Памятка для записи»), сохраняет текст записи как `recording_raw.feature`. Доводка — новая сессия Claude Code, MCP отключён (как в A-generate).

```
Вариант C+, этап «Доводка». MCP на этом этапе не используется.

Используй skill va-scenario-generator, режим 1 «Запись + доводка».
Входы: recording_raw.feature (сырая запись рекордера) и ТестПлан.MD. Другие каталоги не читай.

1. Доведи запись до сценария по чек-листу доводки skill. Шаги, записанные рекордером и не затронутые чек-листом (имена кнопок, закладок, колонок, команд), не меняй. Имена элементов бери только из записи; чего в записи нет — оформи как допущение.
2. Сохрани результат как 01_Заказ_поставщику_Приобретение_ТиУ.feature.
3. Выполни независимое ревью по разделу skill «Независимое ревью» и исправь найденное.
4. Отчёт в C_notes.md: время начала и окончания, таблица дефектов записи (строки записи → дефект → решение), покрытие «Тогда», допущения с уровнем подтверждения (рекордер / БЗ или статистика VA / не подтверждено), число вызовов инструментов.
```
