# Вариант B, фаза «Исследователь»

Официальный ручной режим VA из [docs/AI/examples/ЗапускаемПромптыВРучную](https://github.com/Pr-Mex/vanessa-automation/tree/develop/docs/AI/examples). Скопируйте в рабочий каталог оттуда `InstructionsResearch.md`, `InstructionsWriteScenario.md`, `Правила.MD`, `Memory.MD` (исходный шаблон), а `ОписаниеЗадачи.md` заполните своим тестпланом. В `InstructionsResearch.md` замените имя профиля клиента тестирования на своё. Skills в этой сессии запрещены.

Необязательно: `preflight/command_interface.md` (выгрузка командного интерфейса) и `preflight/preflight.md` (данные базы) — снимают лишние вызовы; без них агент получит то же через MCP.

```
Вариант B, этап «Исследователь». Работай строго по файлам текущего каталога.
Роль: исследователь. Прочитай InstructionsResearch.md, Правила.MD, Memory.MD и строго следуй им. Задача — ОписаниеЗадачи.md.
Уточнения:
- Клиент тестирования уже подключён. Не закрывай его и не завершай процессы.
- Командный интерфейс уже снят: preflight\command_interface.md; данные базы: preflight\preflight.md — используй их вместо повторного get_all.
- База знаний: get_data_from_knowledge_base(format=all) один раз; при превышении размера ответа используй сохранённую выгрузку БЗ.
- Скриншоты — только при ошибках и после проведения документов; сохраняй в png\.
- Результат: РезультатИсследования.MD (формы, имена элементов с типами, кнопки, модальные окна, записанные шаги Turbo Gherkin, где и как проверять каждый пункт «Тогда», раздел «Что изменено в базе»).
- В конце допиши в B_log.md: время начала/окончания, число вызовов инструментов, ошибки.
Skills не используй. Файлы вне текущего каталога не читай.
Если клиент тестирования отключится, переподключи его через manage_test_client — это окружение, итерацией не считается.
```
