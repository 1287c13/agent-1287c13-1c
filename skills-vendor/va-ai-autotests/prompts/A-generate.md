# Вариант A, этап «Генерация»

Запускать в новой сессии Claude Code в каталоге, где лежат только `ТестПлан.MD` и skill. MCP на этом этапе отключён (в каталоге нет `.mcp.json`, инструменты VA запрещены в настройках — см. docs/install.md).

```
Вариант A, этап «Генерация». MCP на этом этапе не используется.

Используй skill va-scenario-generator, режим 3 «Черновик без MCP».
Вход — только ТестПлан.MD в текущем каталоге. Другие каталоги не читай.

1. Напиши сценарий по тестплану по правилам и справочнику шагов skill. Имена полей, колонок и кнопок — только из тестплана и правил skill; всё, в чём не уверен, оформи как допущение.
2. Сохрани результат как 01_Заказ_поставщику_Приобретение_ТиУ.feature.
3. Выполни независимое ревью по разделу skill «Независимое ревью» (по тексту) и исправь найденное.
4. Отчёт в A_notes.md: время начала и окончания, покрытие «Тогда», допущения с уровнем подтверждения (БЗ или статистика VA / не подтверждено), число вызовов инструментов.
```
