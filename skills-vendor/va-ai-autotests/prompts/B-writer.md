# Вариант B, фаза «Писатель»

Новая сессия Claude Code в том же каталоге (инструкции VA требуют новую сессию на каждую фазу). Отличие от официального ручного режима: писателю разрешено самому запускать сценарий и исправлять до 3 раз.

```
Вариант B, этап «Писатель». Работай в текущем каталоге.
Роль: писатель сценария. Прочитай InstructionsWriteScenario.md, Правила.MD, Memory.MD, РезультатИсследования.MD, ОписаниеЗадачи.md.
Отличие от ручного режима VA: тебе РАЗРЕШЕНО самому запускать сценарий — run_scenario + get_test_results, максимум 3 итерации исправления; используй reloadAndRunFromLine с упавшей строки, финальный прогон — reloadAndRun с начала.
Требования:
- Файл: 01_Заказ_поставщику_Приобретение_ТиУ.feature. Перед первым запуском сохрани копию 01_v0.feature и выполни check_syntax (число ошибок запиши).
- Каждому пункту «Тогда» — проверяющий шаг со значением; неавтоматизируемое — // ВЫНОС <n>: <причина>.
- Идемпотентность по базе знаний (служебный комментарий + пометка на удаление документов прошлых запусков, VAExtension установлен).
- После зелёного прогона запусти сценарий ещё раз с начала без ручной очистки — проверка идемпотентности.
- Результат в B_result.md: таблица прогонов (итерация, упавшая строка, причина, классификация: неизвестный шаг / неверное имя элемента / логика-данные / другое), итог, время, покрытие «Тогда» (из 5), результат повторного прогона, diff итогового feature относительно 01_v0.feature.
Skills не используй. Файлы вне текущего каталога не читай.
Если клиент тестирования отключится, переподключи его через manage_test_client — это окружение, итерацией не считается.
```
