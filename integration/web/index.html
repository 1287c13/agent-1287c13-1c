Очередь задач агента 1С

Сервер держит очередь, watcher забирает задачи и передаёт их в Cline. Страница ничего не опрашивает на простое: запросы идут при входе, отправке задачи и пока поставленная задача не завершена.

Вход

Адрес сервера не спрашивается: страница получена с него же, поэтому запросы идут по её собственному адресу. Достаточно ключа клиента.

Ключ хранится в localStorage браузера открытым текстом: любой, у кого есть доступ к этому профилю, сможет поставить задачу. На общем компьютере ключ не сохраняйте, а после работы нажмите «Забыть все ключи».
